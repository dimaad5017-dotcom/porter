# BagGo

Заказ носильщика на московском вокзале. Второе место в технической номинации.

**Прототип: [dimaad5017-dotcom.github.io/porter](https://dimaad5017-dotcom.github.io/porter/)**

Человек с чемоданами идёт через весь вокзал сам. BagGo вызывает носильщика: он
донесёт багаж от входа до вагона или от вагона до зала, за цену, известную
до вызова, и отдаст в руки по коду.

## Как открыть

С телефона — по ссылке выше. С компьютера — скачать
`prototypes/porter/index.html` и открыть двойным кликом. Интернет не нужен,
ставить нечего: картинки, шрифты и данные зашиты в файл, всего 343 КБ.

Весь заказ проходится кликами, ждать таймеры не нужно:

```
плитка «Носильщик» → тап по рамке сканера → «Вызвать»
→ «Пропустить ожидание» → «Пропустить ожидание» → тап по плашке заказа
→ «Пропустить ожидание» → «Получил багаж» → звёзды → «Отправить»
```

## Что умеет

- билет сканером или 14 цифр вручную — вокзал, поезд, вагон, платформа и время
  берутся из него, руками вводить ничего не нужно;
- оба конца пути: уезжающему донесут до вагона, приехавшего встретят у платформы
  и доведут в зал или камеру хранения;
- цена видна до вызова — 190 / 250 / 350 ₽ за первое место в зависимости
  от веса, каждое следующее +50 ₽, с четвёртого работают двое;
- код встречи, оценка с тегами, чаевые фиксированной суммой;
- три вокзала: Ярославский, Курский, Ленинградский;
- тёмная тема и вибрация на события заказа (в браузерах Android).

Носильщик работает внутри здания вокзала: доводит до дверей, ставит багаж,
дальше пассажир идёт сам. За турникеты и на привокзальную площадь он не выходит —
это и есть граница ответственности.
