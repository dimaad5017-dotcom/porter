# alpha

Прототип мобильного приложения для пассажира ВСМ Москва — Санкт-Петербург.
Демо для защиты проекта: работает без интернета и без бэкенда, открывается двойным кликом.

Идея: существующие транспортные приложения считают пассажира абстрактным человеком налегке.
Это — знает, с чем и с кем едет человек, и пересчитывает под него весь маршрут.
Стоянка на ВСМ около двух минут, и для пассажира с коляской это решает всё.

## Прототипы

Каждый — один самодостаточный `index.html`: открывается двойным кликом, работает
без интернета и без бэкенда, все картинки и шрифты зашиты в файл.

| Папка | Что это |
|---|---|
| `prototypes/porter/` | «Носильщик» — заказ носильщика на московском вокзале, актуальная работа |
| `prototypes/ticket/` | пассажир ВСМ, версия «бумажный билет» — четвёртая, принятая |
| `prototypes/light/` | пассажир ВСМ, светлая версия |
| `prototypes/skills/` | пассажир ВСМ, сделан через дизайн-скиллы |
| `prototypes/plain/` | пассажир ВСМ, контрольный вариант без скиллов |

## Структура

- `docs/TZ.md` — техническое задание
- `docs/decisions.md` — журнал решений: что выбрали и почему
- `docs/design/` — дизайн-система и референсы
- `prototypes/` — варианты прототипа

## Окружение

Windows, Python 3.11.9, Node.js v24.15.0 (портативно в `%LOCALAPPDATA%\node`), git 2.53.
Docker не установлен. Для самого прототипа ничего из этого не нужно — только браузер.
