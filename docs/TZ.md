# ТЗ: прототип приложения пассажира ВСМ

Получено 2026-08-16.

## Задача

Интерактивный прототип мобильного приложения для пассажира высокоскоростной магистрали
Москва — Санкт-Петербург (остановки: Тверь, Валдай, Великий Новгород).

Демо для защиты проекта, не продакшн. Приоритет: выглядит и ведёт себя как настоящее
приложение, работает без интернета и без бэкенда.

## Контекст

Стоянка на ВСМ около двух минут — в разы меньше, чем у обычного поезда. Для пассажира
с ребёнком, коляской или крупным багажом это критично: он не знает, где встать на платформе,
успеет ли зайти, кто поможет.

Существующие транспортные приложения считают пассажира абстрактным человеком налегке.
Наше — знает, **с чем и с кем** едет человек, и пересчитывает под это весь маршрут.

## Стек и ограничения

- Один файл `index.html`: HTML + CSS + JS внутри
- Без сборщиков, npm, фреймворков, внешних CDN
- Данные захардкожены в JS-объектах
- Работает при выключенном интернете, открывается двойным кликом
- Комментарии в коде на русском

## Формат экрана

Корпус телефона: 390×812, скругление 38px, тень. Сверху статус-бар (время, связь, батарея).
Снизу таб-бар с 4 вкладками.

## Экраны

1. **Поездка** — приветствие, поле «Куда едете», карточка рейса с обратным отсчётом,
   блок «Со мной»: чипы ребёнок / коляска / крупный багаж / нужна помощь.
   Ядро приложения: чипы пересчитывают экраны 2 и 3.
2. **Маршрут** — пошагово с таймингом: вход → путь к платформе → посадка → в пути → прибытие.
   Время пешком меняется от чипов: налегке 5 минут, с коляской 14 (нужен лифт, не эскалатор).
   Шаги с лифтом помечены; с коляской маршрут только через лифты и пандусы.
3. **На платформе** — схема вагонов с подсветкой своего, крупно «Встаньте у метки 7»,
   обратный отсчёт до прибытия, плашка «Стоянка 2 минуты».
   С коляской — показывать доступную дверь.
4. **Багаж вперёд** — локер на вокзале, багаж едет тем же поездом и ждёт в отеле.
   Три состояния по кнопке: оформить → в пути (прогресс) → доставлен. Цена и время.
5. **Что-то пошло не так** — модалка с кнопкой «Нужна помощь»: маршрут пересобран,
   сотрудник вызван, показано время подхода.

## Главное правило интерфейса

Никаких процентов, рейтингов и списков-каталогов. Один экран — одна мысль.
Крупная типографика, много воздуха, минимум элементов. Цифры, меняющиеся от настроек, —
крупно и заметно, чтобы на защите было видно, что приложение реально пересчитывает.

## Стиль

- Тёмная тема: фон около `#101014`, карточки чуть светлее
- Один акцентный цвет для действий и важных цифр, остальное — оттенки серого
- Системный шрифт, крупные жирные заголовки с отрицательным трекингом
- Скругления карточек 22–26px
- Запрещено: фиолетовые градиенты, шрифт Inter, стандартные «карточки с обводкой»

## Анимации

- Переходы между экранами: появление снизу, 300мс
- Пересчёт цифр при переключении чипа — заметно
- Нажатия кнопок — лёгкое сжатие
- Обратный отсчёт тикает

## Данные для демо

- Рейс Москва → Санкт-Петербург, 2 ч 15 мин, остановки Тверь, Валдай, В. Новгород
- Пассажир: имя, вагон, место
- Два варианта тайминга маршрута: налегке и с коляской
- Локеры для багажа: пара точек на вокзале
