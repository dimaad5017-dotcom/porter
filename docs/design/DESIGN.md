# DESIGN.md — ВСМ, приложение пассажира

Проектная дизайн-система. Основана на семействе **Warm Editorial** (референс — Mercury),
адаптирована под контекст железной дороги и под жёсткое ограничение: прототип
работает офлайн, значит только системные шрифты.

## 1. Атмосфера

Вокзал — не диспетчерская. Пассажир с коляской нервничает, у него две минуты стоянки
и ребёнок на руках. Интерфейс должен успокаивать, а не подсвечивать тревогу неоном
на чёрном.

Основа — бумага, не приборная панель. Кремовый холст, тёплые серые чернила,
один насыщенный цвет на действие. Плотность информации как в расписании,
интонация как в путеводителе.

Настроение: спокойно, внимательно, без спешки — при том что весь продукт про две минуты.

**Отказ от тёмной темы осознанный.** Тёмный фон с одним неоновым акцентом — самый
узнаваемый признак сгенерированного интерфейса. Обе предыдущие версии независимо
пришли к янтарному на почти-чёрном, что подтверждает: это дефолт модели, а не решение.

## 2. Палитра

```
--bg:            #f4f2ed   /* кремовый холст страницы */
--bg-lift:       #eae6dd   /* подложка секции */
--surface:       #ffffff   /* карточка */
--ink:           #22201c   /* основной текст */
--ink-2:         #55504a   /* вторичный */
--ink-3:         #6f6a60   /* подписи, микротекст */
--rule:          #ddd8cc   /* линии */
--rule-strong:   #c4bdae

--accent:        #17603f   /* глубокий сигнальный зелёный */
--accent-press:  #114c32

--warn:          #a8521f   /* только стоянка 2 минуты и сбои */
```

**Акцент — зелёный, и это осмысленно.** На железной дороге зелёный сигнал означает
«путь свободен». Он единственный насыщенный цвет в интерфейсе: действия, ключевые
цифры, активная вкладка. Второго акцента нет.

`--warn` — не второй акцент, а семантическая роль. Разрешён ровно в двух местах:
плашка стоянки и экран сбоя. Больше нигде.

Все цвета текста проверены на контраст к `--bg` по WCAG AA (минимум 4.5:1 для основного
кегля). Первая редакция этого файла содержала `--ink-3: #8b857c` — 3.27:1, провал;
исправлено на `#6f6a60`. При любой правке палитры контраст пересчитывать, а не доверять глазу:
на кремовом фоне тёплый серый кажется читаемым и не является таковым.

## 3. Типографика

Веб-шрифты запрещены (офлайн). Но «системный стек» как отговорка тоже запрещён —
берём конкретные гарнитуры, установленные в Windows, и называем их поимённо.

- **Заголовки:** `Georgia`, далее `Constantia`, `Iowan Old Style`, serif.
  Начертание 400 и 700, трекинг −0.02em. Антиква даёт бумажную интонацию,
  которой нет ни у одного сгенерированного дашборда.
- **Текст и интерфейс:** `Corbel`, далее `Candara`, `Segoe UI`, sans-serif.
  Гуманистический гротеск, заметно теплее и характернее, чем Segoe по умолчанию.
- **Цифры:** тот же Corbel с `font-variant-numeric: tabular-nums`.
  Обязательно на любом числе, которое пересчитывается — иначе оно дёргается по ширине.
- **Моно:** `Consolas` — номер рейса, вагон, место.

Запрещены прямо: Inter, Roboto, Arial, Helvetica, «system-ui» как основная гарнитура.

Шкала: 12 / 13 / 15 / 17 / 20 / 26 / 34 / 46 / 64.

Сочетание «антиква в заголовке + гротеск в тексте» здесь задано намеренно,
а не взято по привычке.

## 4. Компоненты

**Глубина — линиями, не тенями.** Тень разрешена ровно одна: корпус телефона.
Внутри интерфейса разделение делается границей `--rule` или сменой тона.

**Вложенность максимум 2 уровня.** Секция → карточка. Не секция → карточка → плашка → чип.

**Кнопки**
- Основная: заливка `--accent`, белый текст, радиус 999, без тени.
- Вторичная: заливка `--bg-lift`, текст `--ink`, радиус 999.
- Нажатие: сжатие до 0.97, 120мс.

**Карточки**
- Фон `--surface`, граница 1px `--rule`, радиус 22–26px.
- Цветной полосы слева нет ни на одной карточке. Она зарезервирована
  под одну семантическую роль — шаг маршрута, требующий лифта.

**Чипы «Со мной»**
- Выключен: фон `--bg-lift`, текст `--ink-2`, без границы.
- Включён: заливка `--accent`, белый текст.

**Иконки** — одно семейство на весь проект, нарисованное вручную инлайновым SVG,
штрих 1.5px. Не смешивать. Где можно обойтись типографикой — обходиться.

## 5. Движение

Движение объясняет состояние, а не украшает.

- Смена экрана: появление снизу 12px, 300мс, `cubic-bezier(.2,.7,.2,1)`.
- Пересчёт цифры: перекатывание разрядов, 420мс. Это главная демонстрация продукта —
  видно, что приложение действительно пересчитывает.
- Обратный отсчёт тикает без анимации: он и так меняется каждую секунду.
- Мигающих точек, пульсирующих индикаторов и «live»-бейджей нет.
- `prefers-reduced-motion: reduce` отключает всё, кроме смены непрозрачности.

## 6. Запреты по проекту

Сверх общих правил:

- Бирюзовый акцент — нет. Фиолетово-розовые градиенты — нет.
- Стеклянные полупрозрачные карточки — нет.
- Три колонки фич — нет, экраны одноколоночные.
- Проценты, рейтинги, прогресс-бары «заполненности профиля» — нет, это прямо против ТЗ.
- Микротекст пишется под продукт: не «Начать», а «Оставить багаж в локере».

## 7. Самопроверка перед сдачей

- [ ] Акцент один, зелёный; `--warn` только на стоянке и сбое
- [ ] Основная гарнитура названа поимённо, не Inter и не system-ui
- [ ] Вложенность контейнеров не больше 2
- [ ] Теней внутри интерфейса нет, глубина линиями
- [ ] Цветная полоса слева несёт одну роль — лифт
- [ ] Ни одной мигающей точки
- [ ] Все пересчитываемые числа — tabular-nums
- [ ] Подписи кнопок начинаются с глагола и называют действие
